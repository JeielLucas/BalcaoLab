# BalcaoLab

Sistema modular de gestão para varejo, criado como projeto público de portfólio e aprendizagem. O desenvolvimento começa por um PDV com controle de estoque e caixa, com evolução planejada para CRM e loja virtual.

## Objetivo

Construir o sistema gradualmente, fortalecendo práticas de backend, segurança, modelagem de dados e integração com uma interface web. A arquitetura começa como monólito modular, para manter os módulos organizados sem adicionar complexidade antes de ser necessária.

## Tecnologias planejadas

- Java e Spring Boot para o backend
- React e TypeScript para a interface web
- PostgreSQL para os dados
- Docker Compose para o ambiente local de desenvolvimento

Essas são as tecnologias previstas para o projeto; a implementação ainda não começou.

## Visão de evolução

1. Núcleo de PDV, produtos, estoque e caixa
2. CRM integrado ao fluxo de vendas
3. Loja virtual integrada ao catálogo e ao estoque

Cada etapa será planejada e construída depois que a anterior estiver funcional. Recursos de produção, como integração de pagamentos e emissão fiscal, exigem planejamento próprio e não fazem parte do escopo atual.
